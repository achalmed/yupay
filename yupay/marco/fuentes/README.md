# fuentes/ — las fuentes del marco de Yupay

Las nueve que usa el formulario de rendición, copiadas el 2026-10-20 del marco documental de Qillqa (marco_documental/assets/fonts) (las mismas
de la marca, `unancha/tokens/typography.json`): Source Serif 4 (cuerpo), Archivo SemiBold (títulos) e Inter (cifras y
tablas, con números tabulares). Todas bajo la SIL Open Font License 1.1, que permite redistribuirlas con el programa.
Se cargan por nombre de archivo (`../__init__.py` pone esta carpeta en TTFONTS): nada se instala.
